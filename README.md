# Chicago Gardens Faction Drop Randomizer - Optimized

This version is optimized for GitHub Pages/browser upload.

Included:
- Weapon tier display
- Tier 1 = 1–2 star guns
- Tier 1.5 = 1–3 star guns
- Tier 2 = 2–5 star guns
- Animated faction drop spinner
- Four "Your drops" results per spin
- All uploaded gun artwork, converted to lightweight WebP for faster loading

Open `index.html` locally to test.
